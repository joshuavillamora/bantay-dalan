          How scoring works

          For each tested link, the model adds the extra estimated travel time across affected trips and a 30-minute penalty for each trip that becomes unreachable. The candidates are the most-used links on the sampled routes.

          Trip sampling uses one direction per pair. A four-point sample gives up to six trips. The rankings reflect the configured sample and the closures in effect when the analysis ran.

            About measurements

            Each algorithm starts with newly initialized search state on the same endpoints, graph, closures, and routing objective. Compute time excludes shared graph preparation, animation, and drawing. These are single-run browser measurements. Repeated benchmark medians are documented separately.

            Search events can include repeated processing of a vertex. Optimized costs are checked against Standard Dijkstra for the selected objective. Routes and secondary totals may differ even when optimized costs agree. LPA* incremental repair reuses search state and is evaluated separately from full recalculation.
