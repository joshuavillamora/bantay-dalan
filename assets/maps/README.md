# Local vector basemaps

These archives are spatial cutouts of the Protomaps 4.15.2 basemap with OpenStreetMap data as of **2026-11-23 04:00 UTC**. They include data from © OpenStreetMap contributors under ODbL 1.0 and public-domain Natural Earth products. Preserve the map attribution when redistributing the archives. [Protomaps basemap downloads and licensing](https://docs.protomaps.com/basemaps/downloads) · [OpenStreetMap copyright](https://www.openstreetmap.org/copyright) · [Natural Earth terms](https://www.naturalearthdata.com/about/terms-of-use/)

The same ODbL attribution applies to the road graphs and place indexes in the demo. The package includes a copy of the [Open Database License](ODbL-1.0.txt).

The archives are local prepared files kept outside Git by the repository's ignore rule. They are included in the portable demonstration folder. Run the server in `scripts/serve.py` to read them in byte ranges. See the [offline report](../../data/offline.md) for their bounds, exact sizes, extraction commands, and verification.
